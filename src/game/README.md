# src/game

盤面のルールと画面は、このフォルダだけで完結する。数値は `data.ts`、1フレームの判断は `sim.ts`、絵は `draw.ts`。同じ判定を二つに書かない。

やってはいけないことは、各ファイルの先頭コメントが正。ここは役割の地図だけ。

## 盤面

| ファイル | 役割 | 持たないもの |
|---|---|---|
| `types.ts` | 盤面の形 | HP と倍率。数値は `data.ts` |
| `data.ts` | 定数、円陣の配置、HP 式、届く長さ | 1フレームの進行 |
| `sim.ts` | 手毬、花魁、寿司、合成、攻撃 | 描画。手毬をタイマーで落とさない。召喚ボタンは戻さない |
| `draw.ts` | Canvas。金皿の3択もここ | 華と客神一覧。HTML に移すとプレビューで欠けるのは金皿だけ |
| `input.ts` | 盤面の指。マス、合成の開始、札のボタン | 合成の中身は `sim.ts`。客神の配置は `guests.ts` |

届く長さと先端は `swingLen` / `swingTip`。描画と当たりで共有する。`cos` / `sin` で先端を取り直さない。

## 画面

| ファイル | 役割 | 持たないもの |
|---|---|---|
| `GameView.tsx` | 画面の切り替えと HTML。部屋の開閉 | 盤面のルール。金皿の3択。客はここで `step` しない |
| `match-ui.tsx` | 武器、道、敗北、休止の画面 | 誰が押せるか。席は親が見る |
| `shop-ui.tsx` | 店の行と図鑑 | 購入の中身は `picks.ts` / `guests.ts`。P2P は持たない |
| `room-ui.tsx` | 部屋の文言と並び | `Game` も接続も持たない |
| `gacha-ui.tsx` | タイトルのガチャ画面 | 支払いと中身は `gacha.ts`。挑戦中には出さない |
| `DebugPanel.tsx` | 設定とデバッグ | 戦闘のルール。入口はタイトルの設定。右上トグルに戻さない |

札と休止は左下の HTML。一番下が休止、その上が札。Canvas に戻すと重なる。

## 店、札、客神、部屋

| ファイル | 役割 | 持たないもの |
|---|---|---|
| `picks.ts` | 店の購入、武器・金皿・道の3択 | 未知の id では倍率を掛けない。進行は `sim.ts` |
| `items.ts` | 札を買った瞬間と、秒が切れた瞬間 | 効いているあいだの倍率は `sim.ts` が `itemT` を読む。タイトルの店には置かない |
| `guests.ts` | 客神の在庫と配置 | 戦闘の進行。指は `input.ts` |
| `gacha.ts` | 客神ガチャの中身。11連は客神札が1枚は出る | 確率と値段は `data.ts`。12枚目は足さない |
| `net.ts` | 部屋の電文 | 盤面を進めるのは主催の `sim.ts`。客の在庫は上書きしない |
| `persist.ts` | セーブと設定フラグ | `sim.ts` を import しない。店の再計算は `applyMeta` |

## 音と確認

| ファイル | 役割 | 持たないもの |
|---|---|---|
| `audio.ts` | 効果音 | 当たり判定 |
| `mic.ts` | 叫びの倍率 | 攻撃へ掛けるのは `sim.ts` の `screamMul`。拒否されても戦闘は続ける |
| `build-stamp.ts` | タイトルのビルド時刻。日本時間 | 実行のたびに `now` を取らない |
| `play-lock.test.ts` | 届く長さ、客神は合成しない、札の両、武器と金皿の倍率 | 数値を動かす前に落とさない |

方針はリポジトリ直下の [SESSION.md](../../SESSION.md)。
