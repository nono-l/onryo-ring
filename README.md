# 怨霊円陣 / ONRYO RING

円陣に式神を置き、手毬を壊して召喚し、回転寿司レーンの花魁がゴールに着く前に止めるタワーディフェンス。

元ネタの画面録画を見た目・システムの参考にしたが、IP名・キャラ・コピーは使わない。タイトルと式神は日本の妖怪モチーフで別物。

## 動かし方

```
npm install
npm run dev
```

`0.0.0.0:8080` でプレビューする想定（Grok App Builder サンドボックス）。

## コード

ゲーム本体は [`src/game/`](src/game/) だけ見れば足りる。

| ファイル | 役割 |
|---|---|
| `types.ts` | 状態 |
| `data.ts` | 定数・HP式・スロット円配置 |
| `sim.ts` | 1フレームのルール |
| `draw.ts` | Canvas 描画。金皿3択もここ |
| `GameView.tsx` | タイトル等の HTML オーバーレイと入力 |

次の人が触る前に **[SESSION.md](SESSION.md)** を読む。罠と「やってはいけないこと」が書いてある。
